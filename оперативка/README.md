# 📋 ОПЕРАТИВКА - Рабочая папка

**Назначение:** Временные документы, планы, заметки в процессе разработки

---

## 📝 Что здесь хранится

### ✅ Должно быть здесь:
- Незаконченные планы
- Временные задачи и TODO списки
- Заметки по текущей разработке
- Черновики документов
- Debug logs для анализа
- Временные отчеты

### ❌ НЕ должно быть здесь:
- Финальная документация (→ корень или docs/)
- Код (→ src/, core/, adapters/, apps/)
- Конфигурация (→ корень)
- Завершенные отчеты (→ корень)

---

## 🗂️ Структура (пример)

```
оперативка/
├── README.md              - Этот файл
├── current-sprint.md      - Текущий спринт
├── bugs-to-fix.md         - Список багов
├── ideas.md               - Идеи для будущего

│   └── 2025-10-08.md
└── temp/                  - Совсем временные файлы
    └── debug-output.txt
```

## 🔄 Workflow

### Начало новой задачи:
1. Создать файл `task-{название}.md`
2. Описать цель и план
3. Отслеживать прогресс
4. После завершения - удалить или переместить

### Завершение задачи:
1. Обновить главную документацию
2. Удалить временные файлы
3. Обновить `../ACTION_PLAN.md`
4. Обновить `../CHANGELOG.md`

**Приоритет:** Critical / High / Medium / Low  
**Время:** Оценка времени

- [ ] Шаг 1

- [ ] Шаг 3

## Заметки
[Важные моменты, находки]

```markdown

**Статус:** Open / In Progress / Fixed

## Воспроизведение

2. Шаг 2
3. Ошибка

## Ожидаемое поведение

[Как есть сейчас]

## Решение
[Как исправлено]
```

## 💡 Советы

1. **Используйте даты в названиях** - `task-2025-10-08-fix-auth.md`
2. **Удаляйте, не бойтесь** - Всё в git, можно восстановить
3. **Структурируйте** - Используйте подпапки для разных типов
4. **Синхронизируйте** - Завершенное переносите в основную документацию

---

## 🗑️ Когда удалять

**Удалять сразу:**
- Debug output после исправления бага
- Временные тестовые файлы
- Устаревшие TODO списки

**Архивировать:**
- Заметки встреч (старше 3 месяцев)
- Завершенные планы спринтов
- Старые bug reports (fixed)

**Перемещать в docs/:**
- Финальные отчеты
- Завершенные гайды
- Важные решения

---

**Помни:** Эта папка - временное хранилище. Все важное должно попасть в основную документацию!
