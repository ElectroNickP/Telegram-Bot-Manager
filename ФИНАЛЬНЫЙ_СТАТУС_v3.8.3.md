## 🚀 DEPLOYMENT PLAN

### Step 1: Generate Security Keys (2 min)

```bash
python3 << 'EOF'
import secrets
from cryptography.fernet import Fernet
print("# Add these to .env file:")
print()
print("FLASK_SECRET_KEY=" + secrets.token_hex(32))
print("JWT_SECRET_KEY=" + secrets.token_hex(32))
print("ENCRYPTION_KEY=" + Fernet.generate_key().decode())
print()
print("# Optional production settings:")
print("ENVIRONMENT=production")
print("FORCE_HTTPS=true")
EOF
```

### Step 2: Install Dependencies (3 min)

```bash
# If using venv
source venv/bin/activate  # or: . venv/bin/activate

# Install/upgrade dependencies
pip install --upgrade -r requirements.txt

# Verify JWT and crypto libraries
python3 -c "from jose import jwt; from cryptography.fernet import Fernet; print('✅ Libraries installed')"
```

### Step 3: Configure Environment (2 min)

```bash
# Create/edit .env file
nano .env

# Add the generated keys from Step 1
# Set ENVIRONMENT and FORCE_HTTPS as needed
```

### Step 4: Test Locally (5 min)

```bash
# Start application
python3 start.py

# Open browser
open http://localhost:5000

# Test JWT endpoint
curl -X POST http://localhost:5000/api/v2/auth/token \
     -H "Content-Type: application/json" \
     -d '{"username":"admin","password":"admin"}'

# Check logs
tail -f bot.log
```

### Step 5: Git Commits (10 min)

Follow `GIT_COMMIT_PLAN_v3.8.3.md`:
