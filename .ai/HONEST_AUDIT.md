## ❌ КРИТИЧЕСКИЕ ПРОБЛЕМЫ (нужно чинить СРОЧНО)

### 1. **Pytest НЕ может собрать тесты** 🔥
```
ERROR tests/entrypoints - ModuleNotFoundError: No module named 'core.adapters'
ERROR tests/functional/test_full_product.py
ERROR tests/integration/test_migration_integration.py
297 tests collected, 3 errors
```

**Проблема:** 🔥🔥🔥 **НАЙДЕНА КОРНЕВАЯ ПРИЧИНА:**
- `core/entrypoints/factories.py` импортирует `from ..adapters.auto_updater`
- НО: `core/adapters/` НЕ СУЩЕСТВУЕТ
- Реально: `adapters/` в корне проекта
- `core.entrypoints` пытается сделать relative import из `core.adapters`
- Это **архитектурная проблема** - entrypoints в core/, но adapters в корне

**Влияние:** ⚠️ **КРИТИЧНО**
- Тесты НЕ запускаются
- CI/CD сломан
- Auto-test система НЕ работает полноценно

**Решение (2 варианта):**

**Вариант А (Быстрый, 5 минут):**
1. Переместить `adapters/` → `core/adapters/`
2. Обновить все импорты в проекте
3. Структура станет консистентной

**Вариант Б (Правильный, 10 минут):**
1. Исправить `core/entrypoints/factories.py`:
   - Заменить `from ..adapters` → `from adapters`
2. Добавить `sys.path` fix в entrypoints
3. Обновить все relative imports

**Рекомендация:** Вариант А - чище архитектурно

### 2. **Git Hooks НЕ установлены** 🔥
```
❌ .ai/hooks/pre-commit не существует
```

**Проблема:**
- Создали `.ai/hooks/pre-commit-full`
- Но НЕ создали `.ai/hooks/pre-commit`
- Hook НЕ установлен в `.git/hooks/`

**Влияние:** ⚠️ **КРИТИЧНО**
- Автоматизация НЕ работает
- При коммите ничего не проверяется
- Обещанная "автоматика по умолчанию" - не работает

**Решение:**
1. Создать `.ai/hooks/pre-commit` (упрощённая версия)
2. Установить: `ln -sf ../../.ai/hooks/pre-commit .git/hooks/pre-commit`
3. Сделать executable: `chmod +x .ai/hooks/pre-commit`

2. ИЛИ добавить default command в meta-sync.py

### 4. **Auto-test-gen НЕ находит changed files** ⚠️
```
INFO: 🔍 Scanning codebase for testable entities...
INFO: ✅ Found 0 testable entities
```

**Проблема:**
- При запуске с `--diff` находит 0 entities
- Значит `git diff` возвращает пустой результат
- Генератор работает только при full scan

**Влияние:** ⚠️ **СРЕДНЕ**
- Auto-генерация тестов не работает инкрементально
- Нужно сканировать всё каждый раз (медленно)

**Решение:**
1. Исправить `_get_changed_files()` в auto-test-gen.py
2. Добавить поддержку staged files: `git diff --cached --name-only`

- ИЛИ вынести registration в отдельный module initializer
