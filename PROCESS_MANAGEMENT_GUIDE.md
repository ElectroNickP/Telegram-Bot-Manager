# 🚀 Process Management Guide

## Проблема которую мы решили

**ДО:** Проект запускался несколько раз, создавая конфликты процессов и портов.

**ПОСЛЕ:** Умная система управления процессами предотвращает конфликты.

## 🛠️ Новая система управления

### 1. Умный запуск
```bash
# Проверяет конфликты и запускает безопасно
./manage.sh start
```

### 2. Проверка статуса
```bash
# Показывает детальную информацию о процессе
./manage.sh status
```

### 3. Остановка
```bash
# Graceful остановка
./manage.sh stop
```

### 4. Перезапуск
```bash
# Останавливает старый и запускает новый
./manage.sh restart
```

### 5. Принудительная остановка
```bash
# Force kill (только в крайних случаях)
./manage.sh kill
```

## 🔧 Компоненты системы

### 1. `process_manager.py`
- **PID файл управление** - отслеживает запущенные процессы
- **Проверка конфликтов** - предотвращает множественные запуски
- **Graceful shutdown** - корректная остановка процессов
- **Порт проверка** - убеждается что порт свободен

### 2. `start_smart.py`
- **Умный запуск** - проверяет все условия перед запуском
- **Автоматическая установка зависимостей** - устанавливает psutil если нужно
- **Интеграция с process_manager** - использует систему управления

### 3. `manage.sh`
- **CLI интерфейс** - удобные команды для управления
- **Цветной вывод** - понятные сообщения об ошибках
- **Проверка зависимостей** - убеждается что все готово

## 🎯 Как это работает

### При запуске:
1. **Проверка процессов** - ищет уже запущенные экземпляры
2. **Проверка портов** - убеждается что порт 5000 свободен
3. **Очистка конфликтов** - останавливает старые процессы если нужно
4. **Создание PID файла** - сохраняет ID процесса для отслеживания
5. **Запуск приложения** - запускает только если все проверки пройдены

### При остановке:
1. **Graceful shutdown** - отправляет SIGTERM
2. **Ожидание** - ждет корректной остановки (10 сек)
3. **Force kill** - если не остановился, отправляет SIGKILL
4. **Очистка** - удаляет PID файл и освобождает ресурсы
